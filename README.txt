# Mohanned Galal — Portfolio Website

This folder is ready to publish as a static website.

## Main files
- `index.html` — complete responsive portfolio website
- `Mohanned_Galal_CV.pdf` — CV linked to the Download CV button

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and `Mohanned_Galal_CV.pdf` to the repository root.
3. Open Settings → Pages.
4. Choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the website link after deployment.

The website is responsive for mobile, tablet, and desktop.
